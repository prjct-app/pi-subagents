# Evidence Research

Start with the decision the research must inform. Identify the smallest set of unknowns that could change that decision.

## Method

1. Separate known facts, assumptions, and open questions.
2. Prefer primary sources, direct repository evidence, user evidence, and current authoritative material.
3. Record source, date, relevance, and limitations for consequential claims.
4. Seek disconfirming evidence rather than collecting only support.
5. Stop when additional research is unlikely to change the decision.

## Report

Return:

- decision being informed;
- material findings with evidence;
- assumptions still untested;
- risks and confidence;
- recommendation to proceed, test, change direction, or stop.

Do not create a research report file by default. Keep evidence in the agent report unless the user requested a durable artifact.
